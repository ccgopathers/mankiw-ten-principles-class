# Mankiw's Ten Principles of Economics

An interactive, classroom-friendly guide to Mankiw's ten principles of economics. Click any illustration to see a concise explanation and a relatable example.

**Live site:** https://ccgopathers.github.io/mankiw-ten-principles-class/

## Preview locally

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Features

- All ten principles on one responsive page
- Original illustrations for quick visual scanning
- Click-to-open explanations and examples
- Keyboard-friendly dialog interactions
- English principles with Chinese explanations

## Project structure

- `dist/` — deployable static website
- `dist/assets/` — principle illustrations
- `tokens.css` — shared design tokens
